Every payments engineer learns to add an idempotency key to outgoing requests…

## The incident

At 14:02 on a salary day, our provider's API began timing out after 30 seconds…

<Figure src="/images/writing/retry-storm.png" caption="Retries climbing while confirmed payouts stay flat." />

## Why keys alone fail

```ts
// after: key is the payout, persisted first
const key = payout.id;
await ledger.markDispatching(payout.id, attempt);
await provider.payout({ ...req, idempotencyKey: key });
```
